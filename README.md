## 📖 Overview

A high-end, award-winning style interactive digital portfolio built from the ground up for filmmaker **Ebraheem Mohamed**. It transforms a 19-slide cinematic master PDF presentation into an interactive web experience with smooth physics, responsive typography, custom cursor interactions, and video integration.

---

## ✨ Key Highlights

- 🎞️ **1:1 PDF Design Alignment**: Pixel-accurate recreation of all 19 slides using CSS container query units (`cqw`) and exact canvas bounding boxes.
- 🖱️ **Signature Interactive Cursor**: Custom-crafted cinema cursor shaped as the iconic **Ü** with velocity tilt, smooth lerp physics, dynamic gaze direction tracking, natural blinking, interactive winks, and click shockwave ripples.
- 🌊 **Buttery Lenis Smooth Scroll**: 60-120 FPS continuous vertical scroll paired with GSAP `ScrollTrigger` for seamless section transitions.
- 📱 **Adaptive Architecture (Desktop vs. Mobile)**:
  - **Desktop (md+)**: Unclipped natural 16:9 canvas layout with continuous smooth Lenis scrolling.
  - **Mobile (< md)**: Dedicated `100dvh` vertical snap cards with horizontal swipe strips for reels and floating quick-jump pill navigation.
- 🎥 **Video & Reel Integration**: Direct video playback for narrative short films (*Redemption*, *White Lie*, *Black Veil*), commercial campaigns (*Neop TTL*, *Azrak Internship*, *Azrak Ramadan*), documentaries (*Neop × Al Arabiya*, *Neop × Ghalati*), and Instagram Reels (*Nordway*, *Koffie Art*, *NEOP Agency*).
- 🎨 **Cinematic Typography & Grain**: Custom typography featuring **Clash Grotesk** and **IBM Plex Sans Arabic**, backed by a subtle procedural film grain overlay.

## 🚀 Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (recommended) or [Node.js](https://nodejs.org/) (v18+)

### Installation

```bash
# Clone the repository
git clone https://github.com/ameenmv/ebra.git

# Navigate into the project
cd ebra

# Install dependencies using Bun
bun install
```

### Development Server

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site in your browser.

### Production Build & Preview

```bash
# Build for production
bun run build

# Preview production build locally
bun run preview
```
